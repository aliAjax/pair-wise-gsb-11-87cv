# 应急发电机值守台

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand、Ant Design
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

应急发电机值守管理：登记燃油批次及到期日、开机油位、空载/带载时长、排烟温度与异响结论。

## 值守规则

- 燃油距到期不足 30 天、最近带载不足 15 分钟或异响未确认时，机组停在「待处理」
- 送修须写清原因和处理人；复机前补一次带载试机（在修机组登记试机即视为复机）
- 换油记录旧批次、剩余量和报废去向，换油后机组燃油信息自动更新
- 最近状态、待办和换油/送修/试机经历可接着查

数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。
