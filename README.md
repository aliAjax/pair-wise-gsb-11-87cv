# 应急发电机值守台

- 行业：石油
- 技术栈：React、Vite、TypeScript、Zustand、Ant Design
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在原有巡检页基础上扩展的应急发电机值守台：

- **试机登记**：燃油批次及到期日、开机油位、空载/带载时长、排烟温度、异响结论。
- **状态判定**：燃油距到期不足 30 天、带载不足 15 分钟或异响未确认时，机组自动停在「待处理」。
- **送修/复机**：送修须写清原因和处理人；复机前必须补一次带载 ≥15 分钟的试机，否则无法复机。
- **换油登记**：记录旧批次、剩余量和报废去向。
- **查询视图**：最近状态、待办、试机记录、换油经历。

数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。
